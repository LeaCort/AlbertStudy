Preface
This is your first programming course, and it assumes nothing. You do not need to have written a
line of code before. What you do need is a willingness to be precise: a computer does exactly what
you tell it, no more and no less, and most of learning to program is learning to say what you mean
without any ambiguity.
Python is our instrument. It is one of the most widely used languages in the world, and the main
language of data and artificial intelligence — the field this course belongs to. We chose it because it
reads almost like English, because it hides machinery you do not yet need to see, and because nearly
every tool you will meet later in your studies is controlled with Python.
The course has one destination, and every chapter is a step toward it: by the end you will write a
Python program that reads data from a file, transforms it, and writes a new file — and you will be
able to run it again tomorrow, on another computer, and get the same answer. That last property,
reproducibility, is what separates a program you run once and discard from a real tool. We build
toward it in order: first the environment, then the language, then files, then the libraries and ideas
that let your programs reach beyond your own computer.
You cannot learn programming only by reading it, any more than you can learn to swim by reading
about water. So read this book with your hands on the keyboard. Type every example, change it, run it,
break it on purpose, and read the message Python prints. Every chapter ends with exercises do them
before moving on, and check your work against the answers. The error messages that beginners learn
to fear are, in truth, the most patient teacher you will have — this book will teach you to read them.
