# Glossary

*Source: DAT12-2 - Programming in Python - Textbook.pdf, pages 35*

Version of 13 September 2026 Module page
Glossary
For self-study, the key terms of this course, gathered in one place.
argument a value you hand to a function or to the interpreter when you call it.
attribute a piece of data stored on an object, read with a dot and no parentheses:
response.status_code.
bool a type with exactly two values, True and False.
context manager the with statement, which cleans up (e.g. closes a file) for you.
CSV comma-separated values, a plain-text table format.
dict a collection of key → value pairs, looked up by key.
docstring the string just under a def line describing what a function does.
exception Python’s signal that something went wrong; caught with try / except.
f-string a string prefixed with f in which {} is replaced by a value.
float a number with a decimal point, stored with limited precision.
function a named, reusable block of code that takes inputs and returns an output.
index the position of an element in a sequence, counting from 0.
int a whole number of unlimited size.
interpreter the program that reads your Python file and carries out its instructions.
JSON a text format for nested data, mapping onto Python dicts and lists.
list an ordered, changeable sequence, written with square brackets.
logical operator and, or, or not — combines or negates booleans.
method a function that belongs to an object, called with a dot and parentheses.
mutable changeable after creation (a list is mutable; a tuple is not).
object a value that bundles data (attributes) with behaviour (methods); e.g. a string, a list, or a
requests Response.
package a unit of shared code you install with pip and bring in with import.
parameter a placeholder in a function definition, filled in when the function is called.
repr the programmer-facing form of a value, shown by !r in an f-string.
reproducibility the property that a program gives the same result elsewhere and later.
scope the region of a program where a variable exists.
status code a number in an HTTP response reporting success (200) or failure.
str a string, a sequence of characters written between quotation marks.
traceback the report Python prints when an error stops the program.
tuple an ordered sequence that cannot change after it is created.
type the kind of a value, which decides what you can do with it.
virtual environment a project-local folder holding its own packages and interpreter.
