Preface
By the end of this book you will take a business question asked in plain language, translate it into
SQL, run it against a real relational database — from the command line or from Python — and read
the answer back in business terms: joining and aggregating across many related tables, cleaning data
as you query it, and keeping queries fast as the data grows.
Today, working in pandas, you can interrogate a single table held in memory. What you cannot yet
do is query a persistent, multi-table database in the language nearly all of the world’s structured
data lives in. That is the gap this book closes — the foundation the machine-learning work ahead of
you quietly assumes.
