Where to Read Next
This book taught the working ideas; the primary sources below are where they were first set out, for
when you want the depth beneath the summary.
• Git — Scott Chacon and Ben Straub, Pro Git (2nd ed., Apress, free at git-scm.com/book): the
definitive, readable reference for everything in Chapter 1 through Chapter 5.
• How LLMs generate text — Vaswani et al., “Attention Is All You Need” (2017): the transformer
architecture that underlies every model in Chapter 6.
• Few-shot prompting — Brown et al., “Language Models are Few­Shot Learners” (2020): the paper
that showed models learning tasks from a handful of in-prompt examples (Chapter 8).
• Chain-of-thought — Wei et al., “Chain­of­Thought Prompting Elicits Reasoning in Large Language
Models” (2022): the source of the step-by-step reasoning technique (Chapter 8).
